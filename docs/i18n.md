# Localisation

## Why

The agent's environment is a field-facing decision-support tool for Sahelian
smallholder farming contexts, where the primary written/spoken languages are
often French and local languages such as Bambara — not English. A language
switcher is a genuine fit-to-environment feature, not decoration.

## Scope — read this before assuming "the app is translated"

`app/core/i18n.py` translates the **static UI chrome**: title, tagline, form
labels, buttons, tab names, section headers, and risk-level badges. The
analysis now passes the selected language into the recommendation synthesis:
the French result summary, recommended actions, and safety warning are produced
in French in both offline and live-LLM modes.

It does **not** translate:

- technical/raw diagnostic detail (provider names, trace events, sensor
  anomalies, source excerpts, and some limitations) — these retain their
  source language so the evidence is not distorted;
- technical runtime labels in the sidebar (`Environment`, `LLM`, provider
  names) — kept in English deliberately, they describe configuration, not
  the farmer-facing experience.

## Language coverage

| Language | Coverage | Confidence |
|---|---|---|
| English | Full (default; what judges see) | — |
| French | Full, for every translatable key | High |
| Bambara | Core farming vocabulary only (~15 keys: temperature, rainfall, soil, field, farmer, location, recommendation, high-risk badge, tagline). Everything else falls back to French. | **Best-effort, not reviewed by a native speaker** |

The Bambara gap is disclosed in-app (a caption appears when Bambara is
selected) and here, deliberately, rather than shipping fabricated technical
vocabulary under a language label real Sahelian users would recognise as
wrong. Native-speaker review is the natural next contribution.

## Adding a translation

Add or edit an entry in `_STRINGS` in `app/core/i18n.py`:

```python
"my_new_key": {"en": "...", "fr": "...", "bm": "..."},  # "bm" optional
```

Call `t("my_new_key", lang)` from `ui/streamlit_app.py`. Missing `bm` falls
back to `fr`; missing `fr` falls back to `en`.
